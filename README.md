# INK — Quotes

A YourQuote-inspired offline quote browser prototype with 5,000 built-in quotes, categories, search, favorites, copy/share and quote composer.

## Run
Open index.html in a browser. For fetch-based loading, serve the folder locally or host it on GitHub Pages.

## Status
Web prototype, not yet a native Android APK. The current prototype's favorites/custom quotes are session-only. See quotes.json for the bundled collection.

Inspired by the general quote-writing experience of quote apps; original implementation and UI.
